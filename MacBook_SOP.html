Know Your Nzone MacBook Manual Token SOP

Use this guide to extract the Mac app, start a daily token session, identify Nzones for a single customer or an Excel batch, and save your results.

The app supports Apple Silicon Macs, including MacBook Neo A18 Pro, with macOS 13 or later. It opens in one app window. No Python or Node.js installation is required.

1 Extract and open the Mac app

  1. Download the Mac app ZIP supplied by your process owner. The source ZIP is for developers and cannot be opened as an app.
  2. Open Finder, choose Downloads and double-click the app ZIP. Wait until an extracted folder appears.
  3. Open that folder. Find Know Your Nzone Manual Token.app.
  4. Drag the app to Applications, or keep it in an approved folder on your Mac.
  5. Double-click the app. Confirm the normal downloaded-app Open prompt if it appears for the approved signed release.
  6. Wait for Start Nzone Session. There is no separate .command launcher, black application window or browser to keep open.

If macOS reports a damaged app or refuses to open it, contact the distribution owner with the exact warning. The production app must be signed and notarized. A development build may still be blocked by macOS.

2 Start your daily session

  1. Open the token email sent through official Outlook mail.
  2. Enter your Employee ID and Full Name.
  3. Select the correct Use Case: Non-Trade Team Lat/Lon Based Nzone, FleetX Customer Lat/Lon to Nzone, or FleetX Unloading Lat/Lon to Nzone.
  4. Copy the current token exactly and paste it into Mappls Access Token. Do not add quotation marks or the word Bearer.
  5. Click Start Session. Confirm your details and use case appear on screen.

The token remains in memory during the session. It is not saved to disk or included in reports. Enter it again each time you start the app.

3 Process a single customer

  1. Select Single customer.
  2. Enter Customer ID, Customer Name, Latitude and Longitude. Use unloading coordinates when the chosen use case is unloading.
  3. Leave State Name blank initially; the app identifies it from the coordinates.
  4. Click Add Customer and review the row.
  5. Use View Batch Map if you want to check the location.
  6. Click Fetch Nzones. Keep the app open.
  7. Review Status, Nzone Code, Nzone Name and Remark. Click Download Results, choose a folder and save the XLSX file.

4 Enter a manual state when requested

If a state cannot be identified, its Nzone layer is unavailable, or the automatic-state request returns no Nzone, the row shows Manual state required and explains the reason.

  1. Read the row's Remark and check the coordinates.
  2. Enter the correct state in the highlighted manual state field.
  3. Retry Fetch Nzones for the unresolved row.
  4. If it still fails, save the result and share its row error with the support owner. Do not guess a state.

5 Process an Excel batch

  1. Select Multiple/Bulk customers, then Download Template.
  2. Open the XLSX in Excel. Preserve the supplied column names. Fill Customer ID, Customer Name, Lat and Lon. State Name is an optional fallback.
  3. Save as XLSX, choose the file in the app and click Upload Excel.
  4. Review the row count and validation messages. Optionally open the map.
  5. Click Fetch Nzones. Keep the app running and the Mac awake.
  6. Resolve manual state rows, then download the result workbook.

For easier recovery, start with 250 to 500 rows per file. This app limits an uploaded XLSX to 20 MB and processes API requests sequentially. Service limits and token validity can also affect a batch. Already successful Customer IDs are blocked from another paid request.

6 Download history and usage reports

Download History saves successful customer mappings. Usage and Reports provides the admin workbook. Customer-level outputs include Employee ID, Full Name and Use Case. These reports reflect history stored on the current Mac.

7 Troubleshoot and close

Message or issueAction
Token rejected or expiredChoose Change Session and paste the latest token from official mail.
Manual state requiredCheck coordinates, enter the correct state and retry.
Re-hit blockedThis Customer ID is already successful in local history. Use Download History to obtain the existing mapping.
API timeout or network errorCheck the Mac's internet connection and required corporate network access, then retry unresolved rows.
Download not foundLook in the folder selected in the app's save dialog, usually Downloads.
App blocked or reported damagedConfirm you downloaded the approved signed Mac release, and contact its distribution owner with the exact alert.
  1. Finish processing and save all XLSX downloads.
  2. Close the app window or choose Quit. If a batch is still processing, the app asks whether to keep processing or stop.
  3. Enter a new token session the next time you start the app.

Local history is stored under ~/Library/Application Support/Know Your Nzone Manual Token JavaScript. Windows history is not automatically imported. Share the original release ZIP rather than a personal data or output folder.
